# MNNH DHMGS

Unity 6 / URP용 모션 가져오기·재생 패키지.

- 설치: Package Manager → **Add package from git URL** → `https://github.com/so-da-m/dhmgs.git`
- 가져오기: **DHMGS > Importer**에서 서버 주소·Attempt ID 입력 → **Import**.
- 데모: Package Manager에서 **Full Demo** 샘플을 가져와 `DhmgsFullDemo.unity` 실행.
- 다운로드·베이크는 Editor 전용. 생성된 모션과 클립은 빌드에서 재생 가능.
- 설치 시 프로젝트의 HTTP 다운로드가 허용되며 제거 후에도 유지됨.
